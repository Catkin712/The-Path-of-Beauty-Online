# 美的历程 · 主题导览折页

一个博物馆展册风格的线上导览折页，以李泽厚《美的历程》为线索，选取六个时代、六件代表作，
每件配一句「审美关键词」与一段短解读。

**展线**：青铜饕餮 → 楚辞 → 魏晋书法 → 盛唐诗歌 → 宋元山水 → 明清小说
**关键词**：狞厉 → 浪漫 → 风骨 → 气象 → 意境 → 世情

## 站点结构

```
index.html                 单页折页（封面 / 序 / 书影 / 六折 / 结语 / 署名 / 附录）
favicon.svg                印章字标（字形轮廓取自思源宋体）
netlify.toml               Netlify 发布配置（无构建步骤，直接发布根目录）
docs/                      内部文档：文案清单、书影拍摄建议（不进页面，且不对外发布）
assets/
  css/style.css            全部样式（含响应式与打印样式）
  js/app.js                滚动揭示、展线导航、手卷灯箱
  img/*.webp               六件代表作的图版 + 六张书影 + og 分享图 + 图标
  fonts/*.woff2            思源宋体子集（400 / 600），仅含本页用到的字
```

无框架、无构建、无追踪脚本；打开 `index.html` 即可浏览。

## 本地预览

```bash
# 任选其一
python -m http.server 8899
npx serve .
```

然后访问 <http://127.0.0.1:8899/>。

## 部署到 Netlify

仓库根目录已包含 `netlify.toml`，三种方式任选：

1. **连接 Git 仓库**：Netlify → Add new site → Import an existing project → 选择本仓库。
   Build command 留空，Publish directory 填 `.`。
2. **拖拽部署**：把整个目录拖进 <https://app.netlify.com/drop>。
3. **CLI**：`npx netlify-cli deploy --prod --dir .`

## 细节说明

- **纸感**：底色 `#efe9dc`，叠加一层 SVG 湍流噪声（`feTurbulence`）模拟宣纸纤维。
- **折页**：封面有五道折痕（六折页），序章有折页示意图，侧边展线导航可跳转任一折。
- **手卷**：兰亭序与上阳台帖以横幅整卷呈现，点击可查看原尺寸；灯箱支持 ← → 翻页与 Esc 关闭。
- **字**：思源宋体（Noto Serif SC）按页面实际用字子集化，两个字重共约 290 KB。
- **书影**：序之后一节，六张照片摄于小组共用的岳麓书社 2024 年版——封面、目录两页、两节书页、版权页；图注带页码，点开可看原图。
- **署名**：结语之后、附录之前单列「制作名单」，五项分工、排名不分先后，并注明 AI 辅助情形。
- **无障碍**：语义化标签、跳转链接、键盘可操作、`prefers-reduced-motion` 降级、图版均配替代文本。
- **打印**：`Ctrl/Cmd + P` 会输出 A4 竖版页册，共 12 页（封面、序、书影、六折、结语、署名、附录各占一页），可用于线下打印折页。
