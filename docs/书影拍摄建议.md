## 一、为什么要加书影

现在这个页面做得像一个"展览"，但没有任何证据说明**你们真的读过这本书**。六件文物都是公有领域的高清图，文案可以靠二手资料拼出来——评委心里会有这个疑问。

一页书影能同时解决三件事：

1. **可信**：引文旁边就是它所在的纸页，页码一标，无从作假。
2. **可亲**：纸张的纹理、书脊的弧度、页边的磨损，是任何高清文物图都替代不了的"人的痕迹"。
3. **有结构**：目录页一摊开，十章框架与六折的对应关系一眼可见，等于给整页加了一张"地图"。

所以不必多，**三到四页就够**。拍多了反而像扫描件合集。

## 二、怎么选页：三条标准

| 标准 | 说明 |
| --- | --- |
| **有字** | 画面上必须有可读的正文，最好正是网页引用的那一句。整页空白或纯图版页没有意义。 |
| **有痕** | 你们划过线、写过批注、折过角的那一页最好。真实阅读痕迹比干净的书页动人。 |
| **有框** | 画面里带一点页边、页眉或书脊，让人一眼看出"这是一本书"，而不是一张 A4 纸。 |

反之，**不建议拍**：图版页（印刷网点会糊）、纯引文页（像 PPT）、跨页正中（中缝一团黑）。

## 五、加分项：批注页

如果书上有你们自己写的字、划的线、贴的便签——**拍那一页**，它比任何一页正文都珍贵。

要点：
- 挑**批注最密**的那一页，别挑最干净的那页。
- 批注要在画面里清晰可读（用 2× 长焦靠近拍）。
- **不要为了好看重抄一遍批注**。手写的歪斜、涂改、箭头，恰恰是证据。
- 若书是图书馆的、不能写，就把便利贴夹在页里拍，也算。

拍到了，我建议单开一格，图注写「我们读到这里时，写下的」——比任何解说词都强。

## 六、怎么拍：一份可以带去图书馆的清单

### 设备与光线

- [ ] 手机即可，**12MP 以上**，用主摄（不要用前置）。
- [ ] **关掉闪光灯**。闪光灯会打出一块惨白反光，页面上半页都是废的。
- [ ] 找**窗边**，白天，阴天最好。光是斜的（约 45°），纸纹才出来。
- [ ] **关掉头顶的灯**。日光灯管会在画面上留下黄色条纹，后期去不掉。
- [ ] 不要在玻璃展柜、亚克力罩下拍（会映出人影）。

### 角度与构图

- [ ] **手机与页面平行**，正上方俯拍。倾斜会让字"上小下大"。
- [ ] 用 2× 长焦，比 1× 广角更平、畸变更小。
- [ ] 页边**全部入画**，四周留 2 厘米余量（后面要裁）。
- [ ] 画幅**横平竖直**，可以用手机自带的水平仪。
- [ ] 点按页面中心**锁定焦点**，等对焦完成再按。
- [ ] 同一批照片**一次拍完**，保持同一光源、同一张桌子，颜色才会统一。

### 压平（重要）

- [ ] 书页会翘。用**干净的手掌边缘**压住邻近页，拍完裁掉；或请人按住。
- [ ] 图书馆的书**不要折书脊**，不要用玻璃板硬压。宁可拍得稍斜。
- [ ] 每页连拍 3 张，挑最平的一张。手会抖，第一张往往最差。

### 交付规格

| 项 | 要求 |
| --- | --- |
| 数量 | 首选 4 张（01–04）+ 批注页 1 张 |
| 短边 | ≥ 2000 px（大约 8MP 以上） |
| 格式 | **JPG 原图**，不要截图，不要 PNG 转换 |
| 传输 | 网盘 / QQ 文件 / AirDrop。**微信发图即使选"原图"也会被压**，别用 |
| 命名 | `book-01-bronze.jpg`、`book-02-song.jpg`、`book-03-toc.jpg`、`book-04-colophon.jpg`、`book-05-notes.jpg` |

## 七、后期：越少越好

- 只做三件事：**白平衡**（让纸是暖白，不是发青或发黄）、**亮度**（字要黑，纸要透）、**裁切**（拉正、去手指）。
- **不要**加滤镜、不要美颜、不要 HDR、不要"增强清晰度"。一开就假。
- 目标观感：纸色接近 `#f2ece0`（和网页的底色 `#efe9dc` 是同一族），墨色是深灰而不是纯黑。
- 输出：长边 2000–2600 px，JPG 质量 80，单张压到 500 KB 以内。**你们给我原图，我来转 webp、做两档尺寸。**

> 用扫描版 PDF 截图可以吗？可以，但要诚实标成"扫描件"——扫描件没有纸纹和阴影，一眼就能看出，混在照片里反而减分。

## 八、拍好之后，网页上怎么放

**已按方案 A 落地**（2026-10-28）：序章之后单独一节「书影 · 我们读的这一本」，六列网格——第一行封面（2 列）+ 目录双页（4 列），第二行三张等宽（第 043 页 / 第 231 页 / 版权页）。点任意一张可放大；手机端退回单列；打印时收成一页。

当时考虑过的另外两种：

**B. 附录版**
把版权页书影放进附录「参考与延伸」——试过，会让附录左右两栏失衡，最后仍放在「书影」里。

**C. 每折引文旁的小方图（不推荐）**
六折各加一张、配"出处"标注，最有说服力，但会让每折明显变长，且六张照片的风格一旦不统一就全毁。

**现在页面上的图注（可直接改）：**

```
封面　岳麓书社　2024 年 6 月第 1 版
目录　十章，六折取了其中的六章
「狞厉的美」　第二章第一节　第 043 页
「无我之境」　第九章第二节　第 231 页
版权页　岳麓书社 2024 年 6 月第 1 版　第 3 次印刷
```

页码写上去，**这才是书影存在的意义**：把"我读过"变成"我读到第几页"。

## 九、一句话总结

拍**引文所在的那一页**，而不是拍"这本书"。
一页纸 + 一个页码，胜过十张漂亮的书桌摆拍。
