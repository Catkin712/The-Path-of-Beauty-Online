# 书影拍摄建议 · 把《美的历程》的原页放进折页

> 用途：给网页加几页"书本原页"照片，让线上折页与手上这本书发生关系。
> 配套：`docs/文案清单.md`（文案改动）、`index.html`（页面本体）

---

## 一、为什么要加书影

现在这个页面做得像一个"展览"，但没有任何证据说明**你们真的读过这本书**。六件文物都是公有领域的高清图，文案可以靠二手资料拼出来——评委心里会有这个疑问。

一页书影能同时解决三件事：

1. **可信**：引文旁边就是它所在的纸页，页码一标，无从作假。
2. **可亲**：纸张的纹理、书脊的弧度、页边的磨损，是任何高清文物图都替代不了的"人的痕迹"。
3. **有结构**：目录页一摊开，十章框架与六折的对应关系一眼可见，等于给整页加了一张"地图"。

所以不必多，**三到四页就够**。拍多了反而像扫描件合集。

---

## 二、怎么选页：三条标准

| 标准 | 说明 |
| --- | --- |
| **有字** | 画面上必须有可读的正文，最好正是网页引用的那一句。整页空白或纯图版页没有意义。 |
| **有痕** | 你们划过线、写过批注、折过角的那一页最好。真实阅读痕迹比干净的书页动人。 |
| **有框** | 画面里带一点页边、页眉或书脊，让人一眼看出"这是一本书"，而不是一张 A4 纸。 |

反之，**不建议拍**：图版页（印刷网点会糊）、纯引文页（像 PPT）、跨页正中（中缝一团黑）。

## 三、首选三张

> 章节与节标题按**三联书店通行本**（十章本）定位。不同版次页码不同，但**章名、节名一致**，按节标题翻即可，不需要页码。

### 书影 01 · 「狞厉的美」——第壹折的引文出处

| 项 | 内容 |
| --- | --- |
| 拍哪里 | **第二章「青铜饕餮」→ 第一节「狞厉的美」**。翻到这个小标题，拍**标题所在页 + 后一页**（引文可能落在第二页）。 |
| 确认方法 | 页面上能找到这句话：「它们呈现给你的感受，是一种神秘的威力和狞厉的美」。找到它，就拍那一页。 |
| 为什么是它 | 网页第壹折的引文（`B1-11`）逐字来自这里。书影与引文并置，是最省力也最有力的"证据"。 |
| 用在哪里 | 接在第壹折引文下方，或统一放进文末的「书影」小节。 |

### 书影 02 · 「无我之境」——第伍折的引文出处

| 项 | 内容 |
| --- | --- |
| 拍哪里 | **第九章「宋元山水意境」→ 第二节「无我之境」**。读到出现「以物观物」的那一页。 |
| 确认方法 | 页面上有王国维那句：「无我之境，以物观物，故不知何者为我，何者为物」。 |
| 为什么是它 | 这一页同时有王国维的原文和李泽厚的论述，正好对应网页里那句讲究的出处写法（`B5-12`）。一页纸，说明你们分得清谁说了什么。 |
| 用在哪里 | 第伍折，或「书影」小节。 |

### 书影 03 · 目录页——给整页加一张地图

| 项 | 内容 |
| --- | --- |
| 拍哪里 | 书前**目录**，通常两三页。拍**整整一跨页**（左页 + 右页一起入画）。 |
| 确认方法 | 能看到「一 龙飞凤舞」「二 青铜饕餮」……「十 明清文艺思潮」十章。 |
| 为什么是它 | 十章目录与网页的六折形成对照：读者立刻看出你们是从十讲里挑了六讲，而不是随便凑了六个。这是"选题"而不是"摘抄"的证据。 |
| 用在哪里 | 序章之后，「折页示意」旁边。横图，适合做一条通栏。 |

### 书影 04 · 版权页 / 扉页——说明读的是哪个本子

| 项 | 内容 |
| --- | --- |
| 拍哪里 | 书末**版权页**（有 ISBN、版次、印次、定价）或书前**扉页**（书名 + 出版社）。 |
| 确认方法 | 能看到「生活·读书·新知三联书店」和年份。 |
| 为什么是它 | 附录 `A-12` 现在只写了出版社、没写年份。这张照片可以直接补上这个空，也让"参考与延伸"从一句空话变成实物。 |
| 用在哪里 | 附录「参考与延伸」旁。尺寸可以小，但要能看清出版社与年份。 |

## 四、备选：另外四折各有一页

如果时间充裕，可以一折一页。按这个顺序拍（越靠前越值得）：

| 折 | 拍哪里 | 找页方法 |
| --- | --- | --- |
| 第叁折 · 风骨 | **第五章「魏晋风度」→ 第一节「人的主题」** | 页面上有「人的觉醒」四字。网页 `B3-10` 引的正是这个概念。 |
| 第肆折 · 气象 | **第七章「盛唐之音」→ 第一节「青春·李白」** | 小节标题页。若同时拍到「盛唐之音」四个字更好。 |
| 第贰折 · 浪漫 | **第四章「楚汉浪漫主义」→ 第一节「屈骚传统」** | 页面上出现《离骚》或「屈原」。 |
| 第陆折 · 世情 | **第十章「明清文艺思潮」→ 第三节「从感伤文学到《红楼梦》」** | 小节标题页；若拍到「浪漫洪流、感伤主义、批判现实主义」三个词，与 `B6-10` 的高亮完全对应。 |

> 这四页**不拍也不缺什么**。首选三张已经能说明问题；多拍的边际收益在递减，而且每多一页，页面就多一块要处理的内容。

## 五、加分项：批注页

如果书上有你们自己写的字、划的线、贴的便签——**拍那一页**，它比任何一页正文都珍贵。

要点：
- 挑**批注最密**的那一页，别挑最干净的那页。
- 批注要在画面里清晰可读（用 2× 长焦靠近拍）。
- **不要为了好看重抄一遍批注**。手写的歪斜、涂改、箭头，恰恰是证据。
- 若书是图书馆的、不能写，就把便利贴夹在页里拍，也算。

拍到了，我建议单开一格，图注写「我们读到这里时，写下的」——比任何解说词都强。

## 六、怎么拍：一份可以带去图书馆的清单

### 设备与光线

- [ ] 手机即可，**12MP 以上**，用主摄（不要用前置）。
- [ ] **关掉闪光灯**。闪光灯会打出一块惨白反光，页面上半页都是废的。
- [ ] 找**窗边**，白天，阴天最好。光是斜的（约 45°），纸纹才出来。
- [ ] **关掉头顶的灯**。日光灯管会在画面上留下黄色条纹，后期去不掉。
- [ ] 不要在玻璃展柜、亚克力罩下拍（会映出人影）。

### 角度与构图

- [ ] **手机与页面平行**，正上方俯拍。倾斜会让字"上小下大"。
- [ ] 用 2× 长焦，比 1× 广角更平、畸变更小。
- [ ] 页边**全部入画**，四周留 2 厘米余量（后面要裁）。
- [ ] 画幅**横平竖直**，可以用手机自带的水平仪。
- [ ] 点按页面中心**锁定焦点**，等对焦完成再按。
- [ ] 同一批照片**一次拍完**，保持同一光源、同一张桌子，颜色才会统一。

### 压平（重要）

- [ ] 书页会翘。用**干净的手掌边缘**压住邻近页，拍完裁掉；或请人按住。
- [ ] 图书馆的书**不要折书脊**，不要用玻璃板硬压。宁可拍得稍斜。
- [ ] 每页连拍 3 张，挑最平的一张。手会抖，第一张往往最差。

### 交付规格

| 项 | 要求 |
| --- | --- |
| 数量 | 首选 4 张（01–04）+ 批注页 1 张 |
| 短边 | ≥ 2000 px（大约 8MP 以上） |
| 格式 | **JPG 原图**，不要截图，不要 PNG 转换 |
| 传输 | 网盘 / QQ 文件 / AirDrop。**微信发图即使选"原图"也会被压**，别用 |
| 命名 | `book-01-bronze.jpg`、`book-02-song.jpg`、`book-03-toc.jpg`、`book-04-colophon.jpg`、`book-05-notes.jpg` |

## 七、后期：越少越好

- 只做三件事：**白平衡**（让纸是暖白，不是发青或发黄）、**亮度**（字要黑，纸要透）、**裁切**（拉正、去手指）。
- **不要**加滤镜、不要美颜、不要 HDR、不要"增强清晰度"。一开就假。
- 目标观感：纸色接近 `#f2ece0`（和网页的底色 `#efe9dc` 是同一族），墨色是深灰而不是纯黑。
- 输出：长边 2000–2600 px，JPG 质量 80，单张压到 500 KB 以内。**你们给我原图，我来转 webp、做两档尺寸。**

> 用扫描版 PDF 截图可以吗？可以，但要诚实标成"扫描件"——扫描件没有纸纹和阴影，一眼就能看出，混在照片里反而减分。

## 八、拍好之后，网页上怎么放

我倾向**方案 A**，只加一个小节，不加长每一折：

**A. 「书影」横带（推荐）**
放在序章之后、「折页示意」下方。三到四张并排，每张下一行小图注（含页码）。一条通栏，不打断六折的节奏。

**B. 附录版**
把版权页书影放进附录「参考与延伸」的右侧——那里现在只有一行字，太空。成本最低。

**C. 每折引文旁的小方图（不推荐）**
六折各加一张、配"出处"标注，最有说服力，但会让每折明显变长，且六张照片的风格一旦不统一就全毁。

**图注文字可以直接用这几条：**

```
书影 01　《美的历程》「狞厉的美」　第 XX 页
书影 02　《美的历程》「无我之境」　第 XX 页
书影 03　目录：十章，我们取了六章
书影 04　三联书店版版权页
```

页码请按你们手上的本子填——**这正是书影存在的意义**：它把"我读过"变成"我读到第几页"。

## 九、一句话总结

拍**引文所在的那一页**，而不是拍"这本书"。
一页纸 + 一个页码，胜过十张漂亮的书桌摆拍。
